## Qualified browser seam

Source-load results now publish one immutable `timings` record for first
sampled Coverage, settled View, and main-thread batch-publication high-water.
The older main-thread high-water name remains as a deprecated compatibility
alias. Worker completion before the first Coverage publication is rejected as a
stream-validation failure, so a successful result cannot describe an empty
publication.

The private qualification module owns deterministic nearest-rank percentiles,
30-foreground-frame sampling, optional non-standard JavaScript heap capture,
bounded environment capture, and the fixed evaluator. The attended harness
exercises invalid resize without state loss, DPR change and restoration,
hidden rendering and resume, normal disposal and recreation, deliberate Worker
failure before publication, disconnected manifest failure before publication,
cancellation, zero-network persistent warm reuse, display and projection paths,
normalized input, provisional pick, highlight, exact confirmation, and stale
generation rejection.

Deterministic tests cover the unsafe boundaries that are not safely portable to
force in a live browser: failure after partial publication fuses the viewer,
device loss requires recreation, and Worker completion without Coverage fails
closed. The acceptance artifact records `viewer_destroyed` plus an explicit
dispose-and-recreate host action for both recreation-required paths. No physical
device loss or memory-pressure event was forced.
