## Qualified viewer and authority seam

`viewer-api.js` owns asynchronous creation, explicit destruction, visibility,
resize, complete camera replacement, five display modes, immediate and
coalesced rendering, one active Source load, immutable bounded state,
subscriptions, provisional picking, complete highlights, and exact handoff.
`viewer-api.d.ts` declares the same surface and closed error-code union. Tests
compare the runtime display modes and errors directly with the declaration.

The optional `viewer-input.js` retains at most two active pointers and emits
bounded pointer, touch, wheel, and keyboard facts. It owns neither navigation
policy nor key bindings and removes every installed listener on disposal. The
plain host alone maps those facts into orbit, pan, zoom, and projection changes.

Worker transfer record v2 is 32 bytes and preserves Source ordinal, three
relative positions, raw intensity, raw classification, and raw RGB. Wasm
retains at most eight decoded batches / 8,192 Points / 262,144 transfer bytes.
Neutral, elevation, RGB, intensity, and classification changes replace complete
renderer batches at increasing versions without changing Source identity,
Point ordinal, generation, position, Sampled Coverage, or highlight membership.

Picks remain `provisional_gpu_hint`. Highlights remain `presentation_only` and
are complete active-generation replacement sets capped at 32 Points. A new
Source generation clears pick-frame and highlight state. Stale Source,
generation, camera, viewport, destruction, or fused device/surface state cannot
publish old presentation as current.

The checked-in exact bridge accepts only the trusted uncompressed LAS 1.2
format-3 fixture with 34-byte Point records. It validates the deployment,
256-byte Source probe, Source identity, byte length, point count, scale/offset,
strong ETag, identity content encoding, exact `206` range, `Content-Range`, and
body length before decoding exactly one record. It returns ticks, world
position, intensity, classification, and RGB with `exact_source_record`
authority; it never uses sampled GPU position or Attributes as exact values.
