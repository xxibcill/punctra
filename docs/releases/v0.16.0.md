## Qualified deployment and streaming seam

The checked-in deployment manifest binds one immutable 2,380,227-byte LAS 1.2
format-3 representation containing 70,000 Points to Source identity
`c459ff39717b7d6994aaebf344641f5a3add7faf65e249b85933ebd066d1c26e`.
Its fully verified `SourceRecord`, strong ETag, exact length, 256-byte probe,
and compatible 172,808-byte disk-v2 inspection index are deterministic outputs
of the native fixture generator.

The private JavaScript host owns Fetch, credentials mode, Cache API policy,
retry, cancellation, Worker lifecycle, and recovery. One module Worker accepts
one operation and one request at a time. It validates the trusted manifest,
strict `206` response contract, strong validator, exact range totals and
lengths, identity encoding, SHA-256, disk-v2 header/root binding, BLAKE3 sample
checksum binding, sorted unique Source ordinals, world bounds, and finite
relative positions before transferring a batch.

The worker streams the root's Sampled Coverage in four independently bounded
1,024-Point, 24,576-byte buffers. The private Rust Wasm adapter parses the
Source identity, preserves exact ordinals, resets to View 16 generation 1,
validates batch sequence and aggregate limits transactionally, and publishes
four renderer batches. Remote picking remains explicitly unsupported because
this slice does not define exact browser Query confirmation.

Cache policy is caller-selected as `none`, `memory`, or `persistent`. Namespace
and entry keys bind the schema, deployment, Source identity, validator, index
digest, resource, and exact range. Cached metadata and SHA-256 are revalidated
before decode. A fixed-size versioned ledger bounds each namespace to 64 range
entries as well as the declared logical response-body bytes without enumerating
Cache API keys. Quota or API failure does not silently downgrade policy.

The local Python server is qualification tooling, not a production server. It
implements exact single-range `206` responses, CORS header exposure, strong
ETags, identity encoding, immutable/no-transform fixture caching, no-store
host assets, and bounded delay injection for the cancellation probe. It rejects
invalid delay controls with `400` and invalid ranges with `416`.
