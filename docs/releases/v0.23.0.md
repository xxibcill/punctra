## Implementation and authority

The new explicit raster transition uses complementary whole physical pixels
at eight integer progress steps. Incoming and outgoing Source colors remain
opaque, including multisample color coverage and visible-depth/EDL paths.
Nominal pick coverage stays separate. Exact generation, batch key and version
conditions reject stale or invalid updates atomically; recorded frames retain
their captured transition facts. Legacy color-only `PresentationWeight` output
remains unchanged.

The actual native host groups complete refinement and many-to-one coarsening
cuts. It hides replacements before their first presentation, advances only on
successful presentations, pauses without admitting new materialization, and
cancels to the current planner cut. Density uses integer eighth fractions;
FULL coverage retains the legacy count policy. Duplicate residency remains
charged at exactly 24 bytes per Point under existing hard limits.

The private browser fixture controls exercise actual Wasm/WebGPU rendering but
supply authored complete cuts. They add no public SDK child-LOD loader or
public raster-transition controls. Raw numeric arguments reject non-integer,
nonfinite, out-of-range and noncanonical identity inputs before conversion.
Source bytes, exact positions, Query completion and Point Identity are unchanged.
