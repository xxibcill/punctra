## Qualified bounded surface

The qualified public seam prepares one immutable rebuildable Surface Artifact
for an explicit finite inclusive AOI. Its exact Snapshot, Workspace, Source,
Revision, Recipe/AOI, transform, structured metre/metre spatial reference,
terrain algorithm, counts, bounds, and canonical hashes are bound into
checksummed disk-v1 bytes. A file-backed handle exposes separately bounded
canonical vertex and face streams without retaining the whole Surface.

The four successful attempt dispositions are cold `Built`, verified-input
`ResumedInput`, verified-stage `ResumedPublication`, and compatible-target
`Opened`. Publication is descriptor-bound, no-replace, file-synced,
parent-synced, and revalidated. The verified stage and any work pathname remain
after publication because no portable unlink can be conditioned on the open
owned inode. A complete target takes precedence on warm open, and an arbitrary
work sibling is not trusted without verification.

The topology algorithm is still the canonical single-worker full-AOI
triangulator. Complete AOI sorting and topology remain memory-resident under
caller-declared hard limits. Persistence, bounded streams, a large containing
Source, and generated benchmark modes do not make this a true out-of-core
triangulator or establish a production AOI envelope.

## Generated example observations

10,000 vertices, 19,602 faces, and 396 hull vertices. It reported 521,494
topology steps, 135,790,592 algorithm-accounted peak topology working bytes, a
320,480-byte verified input checkpoint, a 556,088-byte complete Surface, an
876,568-byte peak logical work-plus-stage total, and 957 bytes of retained
handle metadata.

A forced one-byte Artifact ceiling retained the verified checkpoint without
publishing a Surface. `ResumedInput` then reused all 10,000 Ground Input Points
with zero Snapshot Point reads and reproduced the uninterrupted Artifact bytes
exactly. Bounded streams consumed all vertices in three batches and all faces
in five batches. The final compatible `Opened` attempt consumed zero Snapshot
Point rows and reported no topology observations.

Per-invocation debug example elapsed values are intentionally not copied. Direct
stage bytes, worker heap, process peak resident memory, allocated filesystem
blocks, QA, LandXML, View, and field accuracy remained explicit JSON `null`
observations. The example does not infer them from adjacent counters.
