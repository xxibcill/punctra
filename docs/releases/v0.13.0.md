## Qualified bounded surface

The qualified public seam prepares one immutable rebuildable Surface Artifact
for an explicit finite inclusive AOI. Its exact Snapshot, Workspace, Source,
Revision, Recipe/AOI, transform, structured metre/metre spatial reference,
terrain algorithm, counts, bounds, and canonical hashes are bound into
checksummed disk-v1 bytes. A file-backed handle exposes separately bounded
canonical vertex and face streams without retaining the whole Surface.

The four successful attempt dispositions are cold `Built`, verified-input
`ResumedInput`, verified-stage `ResumedPublication`, and compatible-target
`Opened`. Publication is descriptor-bound, no-replace, file-synced,
parent-synced, and revalidated. The verified stage and any work pathname remain
after publication because no portable unlink can be conditioned on the open
owned inode. A complete target takes precedence on warm open, and an arbitrary
work sibling is not trusted without verification.

The topology algorithm is still the canonical single-worker full-AOI
triangulator. Complete AOI sorting and topology remain memory-resident under
caller-declared hard limits. Persistence, bounded streams, a large containing
Source, and generated benchmark modes do not make this a true out-of-core
triangulator or establish a production AOI envelope.

### PR #14 remediation qualification

The exact implementation commit includes one focused commit for each reviewed
finding. The first remediation pass bound streams to their originally verified
block checksums, rejected raced FIFO parent and leaf paths without blocking,
released the derived Surface before staged readback, delayed terminal progress
until durable success, shared stage publication, and shared the bounded stream
driver. The final pass made Linux publication independent of retained stage
pathnames, aligned the exact completion pointer, distinguished conflicting
targets from corrupt recognized artifacts, shared persistent binding decoding,
and centralized stream section metadata.

The clean full matrix above ran only after those commits were complete. The
final attestation changes only this verification record and the repository's
completion pointers; it does not change the qualified implementation or
package payload.

### Focused acceptance counts

The point-terrain package run reported 54 core tests, 13 persistence integration
tests, five public persistence-acceptance tests, and three passing frozen-v1
fixture tests plus one explicitly gated ignored fixture-regeneration test. The
terrain-demo run reported 105 library tests, 17 workflow tests, and 10 process
tests. The renderer-demo headless suite reported 13 tests.

The persistence suites cover deterministic bytes across Source row batches;
legacy/persistent topology equality; all four dispositions; zero-row warm open;
Snapshot, Recipe/AOI, algorithm, transform, and spatial-reference staleness;
complete/work truncation and corruption; invalid offsets, order, winding,
references, counts, hashes, and checksums; cancellation and I/O faults at
durable boundaries; publication certainty and races; independent inclusive and
one-under resource limits; and bounded multi-block vertex/face streams with
post-yield mutation detection.
